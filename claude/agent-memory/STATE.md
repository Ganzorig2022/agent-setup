## Lessons Learned
- `~/.claude/rules/*.md` tends to auto-load into EVERY session globally. The cause is a parser bug, not a missing feature: `paths:` is CSV-parsed, so a YAML array or a *quoted* value silently matches nothing, while `paths: **/*.ts,**/*.tsx` unquoted works. CC #19377/#16299 open, #21858 closed as duplicate, with a later report that all `~/.claude/rules` load regardless. Treat user-level path scoping as unreliable — keep project-specific context in project CLAUDE.md imports.
- CLAUDE.md + always-on rules are the main per-turn token cost — keep them lean; push detail into skills/agents (lazy-loaded).
- Claude Code internals — subagent CLAUDE.md/@import loading, `model:` frontmatter, settings.json hook paths + output channels, headless `claude -p` permission-mode trap, SubagentStop payload fields — live in the `claude-code-internals` skill. Load it before editing hooks, settings.json, or agent frontmatter.
- Browser-automation gotchas (chrome-devtools-axi persistent profile + npx-by-absolute-path under launchd, X.com read/write mechanics, Draft.js composer traps, Bluesky RSS as the token-free proxy) live in the `chrome-devtools-axi` skill — load it before any X or headless-browser work.
- Telegram Bot API = free unattended push channel for local automations: @BotFather bot creation is free (no billing/card); the user must message the bot ONCE before it can DM them (grab `chat_id` from `getUpdates`); `token`+`chat_id` in env; `sendMessage` caps at 4096 chars so chunk long messages.
- The auto-mode classifier blocks Claude from editing `.claude/settings*.json` permissions, from `mv`/`rm` of pre-existing repos, from `cp -R` that creates a new directory inside a repo, from installing plugins from external repos, from read-only `SELECT`s against a `users` table (enumeration shape), from looping login attempts across many accounts (credential-stuffing shape, even against the user's own API), and from credential-probing shapes (`git credential fill`, reading `~/.netrc`) — even with in-chat user approval. Don't retry; hand the exact command to the user to run via the `!` prefix. Same handling for the user's own `~/.claude/hooks/block-dangerous.sh` PreToolUse hook, which blocks `rm -rf` and `git reset --hard` ("… is not allowed. Do it manually if intentional") — hand it over, never route around it; a fresh `git worktree` is a legitimate alternative for a clean baseline, not a workaround. The hook matches the **command text**, so a command that merely quotes a blocked string (e.g. writing these very facts to a file) is blocked too — use the Edit/Write tools for that, not Bash.
- Demo/seed account credentials **drift in production** — verify with a real API login immediately before publishing them anywhere (App Store demo account, tester handouts, docs). A stale one cost a **Guideline 2.1 rejection** and a month of review round-trips. A generic `INVALID_CREDENTIALS` response cannot distinguish "no such user" from "password changed", and the ways to find out (password-reset, register probe) have real side effects — don't.
- User's daily terminal is cmux (com.cmuxterm.app) — a plain terminal emulator, so tmux runs fine inside its panes; only sessions needing phone-mirror must live in tmux. Phone is a Xiaomi (MIUI) — exclude Tailscale from battery optimization or it gets killed in background.
- launchd python jobs CANNOT read or write `~/Desktop` subtrees created from a terminal context — per-file `com.apple.macl` TCC ACLs make globs silently return empty and writes fail `Errno 1` — and the failure is silent enough to blind a script's own idempotency checks. Keep automation output in `~/<dir>` and symlink onto Desktop for visibility. Related: lid closed with `SleepDisabled=1` keeps the Mac running but Wi-Fi is often down at launchd fire time; calendar jobs are never lost to sleep (they fire once at next wake, lost only on shutdown) — gate network stages with long retries, don't trust the scheduled slot.
- Boolean quality gates render "no evidence" as a verdict — a rate over zero samples reads as *failed*, and a gate met by one source class reads as *passed*. Use `passed`/`failed`/`insufficient_evidence` with a per-class minimum-sample threshold, and persist the counts next to the state.
- Scanned/image PDFs: the Read tool fails with "pdftoppm is not installed" and `pdftotext` is also absent on this Mac. Render with the built-in `qlmanage -t -s 2400 -o <dir> file.pdf` then Read the resulting PNG — no install needed. A PDF containing `/Image` and no `/Font` has no text layer at all, so stream/zlib extraction returns zero characters; go straight to rendering.
- Two browser tools: **Claude-in-Chrome MCP** acts inside the session-account's Chrome profile (can differ from the user's own login) and sees only tabs in its own group — reopen the page inside the group; **computer-use** screenshots the display but browsers are read-tier (no click/type). Multi-monitor: `switch_display auto` + re-screenshot. Accessibility labels from `find` can be wrong (a delete button read as "edit") — map row controls by position via `read_page`, re-read after each change. First `screenshot` after a `navigate` often renders blank grey — `scroll` (it returns an image) or a second shot paints it; tab groups also vanish between turns, so call `navigate` standalone to re-create rather than reusing a stored `tabId`. (Meta console gotchas → `mobile-release-ops`.)
- New Vite 8 scaffolds: TS 6 rejects `baseUrl` (TS5101 — use `paths` alone); the template ships oxlint, not eslint; non-interactive shadcn = `pnpm dlx shadcn@latest init -t vite -b radix -p nova -y --no-monorepo` (presets nova/vega/maia/…; there is no `--base-color`).
- Claude Design (`/design`) preview: taps inside artboards don't fire in the local read-only copy — check states via tweak chips; Chrome MCP refuses `file://`, serve the seeded HTML with `python3 -m http.server`; first capture is blank while mounting (~10 s); sticky notes overlap the artboard name strip unless y ≤ −300; seed previews with `--canvas` or frames clip at default slots; full mount ≈20 s.
- zsh doesn't word-split `$VAR` — a variable holding several CLI flags arrives as one argument; spell flags out or use `${=VAR}`.
- Chrome MCP + PWA: after a rebuild the service worker serves the PREVIOUS bundle on first load — navigate twice (or `?v=` bust) before judging a change.
